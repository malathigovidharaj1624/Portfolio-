MALATHI G — STATIC PORTFOLIO

Files:
- index.html       Portfolio content and page structure
- style.css        Responsive styling and sky-blue palette
- script.js        Mobile navigation, scroll reveal, and footer year
- assets/sky-reference.jpg  User-provided sky image used for the color mood/background

HOW TO RUN:
1. Extract the ZIP file.
2. Open the malathi-portfolio folder.
3. Double-click index.html to open it in a browser.

No framework, build step, or server is required. Google Fonts are loaded online; system fallback fonts are included.

Before publishing:
- Verify the phone number and email address.
- Add your real LinkedIn profile URL if you want a LinkedIn button.
- Keep the skills and experience accurate to what you have actually learned.
